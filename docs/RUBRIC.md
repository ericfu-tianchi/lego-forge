# Review rubric

Score each row 1–10 from the renders (`out/sheet.png`, `out/hero.png`, and `out/compare.png` for a picture). Be strict: 7 = "a good
fan design", 9 = "could be an official set". Write the scores in brief.md every round; fix the lowest row first.

| row | 10 looks like | 4 looks like |
|---|---|---|
| **Recognisable** | the subject is obvious in one second from the hero view; every signature feature is built clearly and in the right place | you need the title to know what it is; signature features missing or implied |
| **Proportion & scale** | silhouette and ratios match the subject/picture; one scale throughout | squat or stretched; a minifig next to a micro building; a door taller than the storey |
| **Structure** | check PASS; looks like it would survive being picked up; joints overlap; no part hangs on nothing visually | PASS but looks fragile or illogical (thin towers on one stud, details glued to air) |
| **Detail & texture** | every face has something; smooth tiles where smooth, studs where texture; 25–50% specialty parts; nothing reads as a blockout | big blank walls, studs everywhere, only plain bricks |
| **Colour** | 4–8 colours from the subject; clear main/secondary/accent; base neutral | rainbow, or one flat colour; accents everywhere |
| **Composition** | front faces the viewer; the set is framed by a base sized to it (scenes); 1–3 figures doing something legible; a small story | empty base or crammed base; figures standing around; the best side hidden |

**Critical failures** (fix before anything else): the checker fails; the subject is unrecognisable; parts float in the renders; the
model is mostly hidden inside the base; more than 2,000 parts.
